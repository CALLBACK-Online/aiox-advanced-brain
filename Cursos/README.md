# Cursos — AIOX Advanced Brain

Hub das trilhas educacionais deste repositório. Cada curso é **autocontido** (links internos resolvem dentro da própria pasta). Entre cursos, use os caminhos monoespaçados ou abra pelo arquivo indicado.

## Navegação recomendada: Obsidian

Os cursos usam Markdown com **wikilinks** (`[[…]]`). A forma recomendada de estudar é abrir esta pasta (ou um curso específico) como **vault no [Obsidian](https://obsidian.md)**:

1. Instale o Obsidian.
2. **Open folder as vault** → selecione `Cursos/`, ou `Cursos/AIOX Advanced/`, ou `Cursos/AIOX-Advanced-Squads/`.
3. Comece pelo `README.md` do curso e siga os links; use Graph view / backlinks se quiser o mapa.

No GitHub ou em editores genéricos os arquivos abrem, mas o grafo de ~1.600 links do AIOX Advanced funciona melhor no Obsidian. Instruções completas: README na raiz do repositório.
