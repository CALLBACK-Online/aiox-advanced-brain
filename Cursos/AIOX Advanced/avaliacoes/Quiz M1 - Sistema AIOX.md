# Quiz M1 — AIOX como sistema

Eu respondo sem consultar as aulas. Depois abro o gabarito, explico cada erro com minhas palavras e volto à evidência do módulo. Minha referência de domínio é 80%.

## Questões

### 1. As quatro camadas da anatomia de um agente AIOX são:

- A. Persona, Skills, Autoridade, Memória
- B. UI, API, DB, Deploy
- C. Prompt, Temperature, Top-p, Stop
- D. PO, Dev, QA, DevOps

### 2. Na escolha dos 4 executores, o centro da decisão é:

- A. Qual modelo de LLM está na moda
- B. Sempre o agente, para maximizar autonomia
- C. Sempre o humano, para evitar risco
- D. A task — o executor é escolha (humano/agent/clone/worker)

### 3. O núcleo de gravidade que os agentes orbitam inclui tipicamente:

- A. Somente o histórico do chat da sessão
- B. CLAUDE.md + core-config + artefatos de produto (PRD/stories)
- C. Apenas o README do monorepo
- D. Somente settings.local.json

### 4. Quando usar @ versus / na prática AIOX?

- A. @ e / são sempre equivalentes
- B. / só serve para instalar pacotes npm
- C. @ carrega persona; / dispara ritual/comando com greeting e processo
- D. @ é proibido em projetos brownfield

### 5. AIOX Advanced posiciona AIOX principalmente como:

- A. Software house operável no computador (agentes + processo + QA)
- B. Mais um autocomplete no editor
- C. Substituto total de qualquer dev humano
- D. Plugin visual no-code para founders

<details>
<summary>Gabarito comentado</summary>

**1. A** — Persona (quem), Skills (o que faz), Autoridade (o que pode), Memória (o que carrega).

**2. D** — Task no centro; cada executor tem custo, determinismo e confiança diferentes.

**3. B** — Sem núcleo coerente, cada agente inventa uma verdade.

**4. C** — Sintaxe define tipo de contexto. Sem processo, @ solto vira chat genérico.

**5. A** — A tese do curso: organização multi-agente com processo, não ferramenta isolada.

</details>
