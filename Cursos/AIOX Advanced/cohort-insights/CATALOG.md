## Como usar (alunos e mentores)

1. `Cmd/Ctrl+F` neste arquivo com o nome do pack (`squad`, `design`, `token`, `hormozi`…).
2. Pegue só o bloco **LATEST**.
3. Se o arquivo ainda estiver só no export do WhatsApp, peça no grupo: *"catálogo diz LATEST = X — alguém reenvia?"* ou baixe do export local.
4. Depois de baixar: rode `*validate-squad` / upgrade quando for squad — zip solto não basta.
