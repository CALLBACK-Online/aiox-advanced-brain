### Phase 1 — Bootstrap & Core ({{phase1_effort}})

- [ ] Add `source "$RUNNER_LIB_DIR/pipeline-bootstrap.sh"` as first source
- [ ] Replace direct `claude -p` calls → `run_llm_prompt()`
- [ ] Export `METRICS_FILE` path
- [ ] Add `check_cost_cap "$MAX_COST"` after each phase
- [ ] Verify `record_metrics()` is auto-called by `run_llm_prompt()`

```bash

METRICS_FILE="$RUN_DIR/metrics.jsonl"
```

### Phase 2 — State Management ({{phase2_effort}})

Replace custom state tracking with `state-manager.sh`.

- [ ] Remove custom `STATE_FILE` write logic
- [ ] Use `state_init()` to initialize
- [ ] Use `state_phase_update()` for phase transitions
- [ ] Use `state_complete()` on success
- [ ] Test resume: kill mid-run, verify restart from correct phase

```bash
# Replace custom state writes:
state_init "$STATE_FILE" "$TARGET_SLUG" "runner" "{}"
state_phase_update "$STATE_FILE" "$phase_id" "running" "$RUNNER_NAME"
state_phase_update "$STATE_FILE" "$phase_id" "complete" "$RUNNER_NAME"
state_complete "$STATE_FILE" 0
```

### Phase 3 — Session & Output ({{phase3_effort}})

Add session lifecycle and output sanitization.

- [ ] Add `session_start "$SESSION_DIR"` before first phase
- [ ] Add `session_end "$SESSION_DIR"` on completion
- [ ] Wrap all LLM output through `filter_llm_output()`
- [ ] Use `truncate_prior_context()` before injecting prior phase outputs

```bash
session_start "$SESSION_DIR"
# ... phases ...
raw_output="$(filter_llm_output "$raw_output" "$log_file")"
session_end "$SESSION_DIR"
```
