# Brand Squad — Production Examples

Outputs do squad `brand` são artefatos canônicos de marca que vivem no project docs, não no filesystem do squad.

## Onde os outputs reais vivem

| Tipo | Localização canônica |
|---|---|
| Brand platform (naming, positioning, tagline) | `docs/tactical/brand/` |
| Brand assets (logos, identidade visual) | `docs/tactical/brand/assets/` |
| Campaign briefs que usam brand | `docs/operational/campaigns/{slug}/brand/` |

## Evidência de uso

O squad foi executado para múltiplas BUs (aiox, casting, your-business) — artefatos de marca ficam em `docs/` no projeto do aluno. Ver `docs/*/tactical/brand/` para evidência atual.

## Templates canônicos

- `squads/brand/templates/` — templates usados em cada execução
- `docs/schemas/campaign-brief-schema.yaml` — schema ADR-012 para cross-squad brand briefs

## Provenance

Outputs são artefatos canônicos sob governança do Document Registry, lifecycle PLACEHOLDER → POPULATED → VALIDATED → APPROVED. Não copiados aqui porque são específicos de cada BU e vivem no project docs.
