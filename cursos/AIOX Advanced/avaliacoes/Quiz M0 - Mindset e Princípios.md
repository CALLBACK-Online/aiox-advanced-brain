# Quiz M0 — Mindset e princípios

A. Definir problema, processo e evidência de término
B. Escolher o modelo
C. Criar o squad
D. Instalar MCPs

### 2. Qual uso respeita Token Economy?
A. Colocar todo o acervo no contexto
B. Repetir o briefing em cada prompt
C. Carregar apenas o contexto necessário para a decisão atual
D. Nunca registrar decisões

### 3. O que “não delegar o pensar” exige?
A. Fazer tudo manualmente
B. Manter julgamento, critérios e responsabilidade com o operador
C. Evitar agentes
D. Eliminar automação

### 4. Qual evidência mostra pensamento estruturado?
A. Prompt longo
B. Muitas ferramentas
C. Resposta rápida
D. Decisão, premissas, fronteiras e critério de aceite explícitos

### 5. Você quer usar IA para gerar contratos de um squad jurídico, mas seu conhecimento de direito é achismo vestido de conhecimento (caixinha C). Qual é o movimento certo?
A. Operar mesmo assim, compensando com um prompt bem detalhado
B. Usar o repertório forte que você tem em outra área para julgar o output
C. Reconhecer a pretensão e consultar especialista, estudar ou não operar nessa área
D. Pedir para a própria IA validar a qualidade jurídica do que gerou

### 6. Você vai escrever o PRD de um produto novo e pensa em usar um modelo mini para economizar tokens. O que diz o Token Economy Mindset?
A. Faz sentido: PRD é texto, qualquer modelo resolve
B. Use o modelo do meio, que equilibra custo e qualidade
C. Economize agora e refine o PRD depois com o modelo topo
D. Errado: decisão estratégica pede o modelo topo; o barato fica para tarefa mecânica e reversível

### 7. Pela terceira semana seguida você repete a mesma conversa longa com a IA para revisar seu relatório, corrigindo os mesmos pontos. O que “respeite o processo” manda fazer?
A. Capturar a conversa que funcionou, extrair os passos e transformá-la em comando reutilizável
B. Continuar na conversa: se funcionou três vezes, está validado
C. Trocar de modelo até algum acertar de primeira
D. Colar todas as correções antigas no início de cada novo chat

### 8. Você vai pedir à IA o banco de dados de um sistema de assinaturas. Como aplicar “não delegue o pensar”?
A. Delegar o modelo de dados inteiro: a IA conhece os padrões do mercado
B. Decidir você a arquitetura e as entidades, e delegar a execução dentro do desenho, com gate no final
C. Rodar em Yolo mode e revisar tudo de uma vez no fim da sessão
D. Pedir três opções de schema e escolher a mais completa
