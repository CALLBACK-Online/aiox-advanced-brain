# Quiz M7 — Criar um Squad próprio

Eu respondo sem consultar as aulas. Depois abro o gabarito, explico cada erro com minhas palavras e volto à evidência do módulo. Minha referência de domínio é 80%.

## Questões

### 1. REUSE > ADAPT > CREATE ordena:

- A. CREATE primeiro por diversão
- B. Nunca reutilizar open source
- C. Buscar o que existe, adaptar se couber, criar só com gap comprovado
- D. Só ADAPT

### 2. Antes de criar squad, a triagem pede:

- A. Prior-art + research loop + decisão REUSE/ADAPT/CREATE
- B. Só entusiasmo
- C. Apagar o core AIOX
- D. Fork sem busca

### 3. Squad Creator passo a passo ainda exige:

- A. Zero validate
- B. Só um prompt 'cria um squad de marketing'
- C. Apagar CLAUDE.md
- D. Mapa de entidade/órbita e prior-art antes de generate

### 4. Você encontrou um Squad parecido com o que precisa, mas ele não cobre uma etapa crítica do seu processo. Qual sequência respeita a heurística do curso?

- A. Descartar e criar tudo do zero
- B. Validar prior art, reutilizar o núcleo, adaptar a lacuna e criar apenas o que faltar
- C. Duplicar o Squad e renomear os agentes
- D. Adicionar mais personas antes de testar uma Task

<details>
<summary>Gabarito comentado</summary>

**1. C** — Anti-NIH com prova de busca.

**2. A** — Fase-zero evita duplicata.

**3. D** — Creator sem mapa duplica confusão.

**4. B** — REUSE > ADAPT > CREATE reduz NIH e obriga a criação nova a justificar seu custo.

</details>
