# Quiz M2 — Setup operacional e contexto

Eu respondo sem consultar as aulas. Depois abro o gabarito, explico cada erro com minhas palavras e volto à evidência do módulo. Minha referência de domínio é 80%.

## Questões

### 1. Acima de certos limiares de janela de contexto, o problema principal é:

- A. O preço do domínio na Vercel
- B. Impossibilidade de usar Markdown
- C. Bloqueio permanente de git push
- D. Degradação de qualidade — contexto demais vira ruído

### 2. Em engenharia de contexto, uma faxina saudável prioriza:

- A. Apagar o git history
- B. Cortar comandos/skills/MCPs e CLAUDE.md inchado que ocupam janela sem valor
- C. Desligar todos os quality gates
- D. Trocar o laptop

### 3. Sweet spot de formatos para LLM no AIOX tende a ser:

- A. Tudo em JSON binário
- B. Somente PDF escaneado
- C. YAML para config/contrato, Markdown para prosa, JSON quando schema rígido importa
- D. Somente conversa oral sem artefato

### 4. Paralelizar várias stories em subagents para 'economizar contexto':

- A. Pode isolar contexto por task, mas multiplica gasto de tokens
- B. Sempre economiza dinheiro e tempo
- C. É proibido no AIOX
- D. Só funciona sem git

### 5. Budget mental citado no campo para CLAUDE.md é da ordem de:

- A. Ilimitado — quanto mais regras melhor
- B. Exatamente 10 linhas sempre
- C. Só emojis e links
- D. ~150 instruções úteis; centenas de linhas viram ruído

<details>
<summary>Gabarito comentado</summary>

**1. D** — Janela não é 'quanto mais melhor'; engenharia de contexto corta peso morto.

**2. B** — Contexto é real estate caro — o mesmo músculo de token economy.

**3. C** — Cada formato é contrato de atenção do modelo — não religião de um único tipo.

**4. A** — Insight de campo da cohort: isolamento ≠ economia de fatura.

**5. D** — Campo Advanced: 461 linhas vs ~150 instruções — reestruturar.

</details>
