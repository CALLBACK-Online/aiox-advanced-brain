# Quiz M9 — Design System AIOX

Eu respondo sem consultar as aulas. Depois abro o gabarito, explico cada erro com minhas palavras e volto à evidência do módulo. Minha referência de domínio é 80%.

## Questões

### 1. Design system como decisão significa:

- A. Só escolher cor favorita
- B. Proibir Storybook
- C. Repetir decisões de interface via tokens/componentes/contrato
- D. Gerar UI sem leitura de DESIGN.md

### 2. DESIGN.md existe para:

- A. A IA (e humanos) lerem o contrato antes de gerar tela
- B. Ocultar tokens do time
- C. Substituir git
- D. Só marketing

### 3. Storybook de variantes prioriza:

- A. Só happy path light desktop
- B. Screenshots aleatórios sem critério
- C. Desligar a11y
- D. Matriz dark/a11y/responsive e correção na raiz (token)

### 4. As telas geradas estão funcionais, mas cada uma inventa espaçamento, estados e comportamento responsivo. Qual intervenção ataca a causa?

- A. Polir cada tela separadamente
- B. Formalizar decisões no DESIGN.md e provar componentes e variantes no Storybook
- C. Trocar Tailwind por CSS puro
- D. Gerar mais três versões de cada tela

<details>
<summary>Gabarito comentado</summary>

**1. C** — Decisão > estética solta.

**2. A** — Contrato legível por máquina.

**3. D** — QA em massa, não catálogo de vaidade.

**4. B** — Deriva visual nasce da falta de contrato e de prova sistemática das variantes.

</details>

## Transferência

Eu produzo esta evidência no meu projeto: Contrato visual, taxonomia de componentes e Storybook cobrindo responsividade, dark mode e acessibilidade.
