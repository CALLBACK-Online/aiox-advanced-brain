# Storybook

Catálogo isolado de componentes e variantes de UI. No AIOX, vira superfície de decisão visual e de QA de composição — não só demo.

## Como é usado

Use **Storybook** como catálogo isolado de componentes e variantes de UI — e, no AIOX, como superfície de decisão: é onde variantes são comparadas, escolhidas e revisadas antes de entrar na composição das telas.

**Exemplo prático:** nas aulas [[56-tailwind-shadcn-storybook]] e [[57-storybook-para-variantes]], crie Stories de Button default, loading, erro e dark; revise as variantes antes de montar a tela ([[42-design-atomico-brad-frost]]).

**Não confunda:** **Storybook** é catálogo de componentes, não aplicação final. Também não é a **Story** do backlog: os nomes se parecem, mas os artefatos têm funções diferentes.
