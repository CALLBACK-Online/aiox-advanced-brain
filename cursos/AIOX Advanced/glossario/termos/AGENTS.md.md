# AGENTS.md

Arquivo de regras permanentes do projeto: escopo, convenções, paths, comandos e limites que mantêm as sessões consistentes.

## Como é usado

Leia **AGENTS.md** antes de executar uma tarefa para descobrir as restrições do projeto, a fonte de verdade, os caminhos canônicos e os gates obrigatórios.

**Exemplo prático:** na aula [[11-goal-vs-loop]], consulte o **AGENTS.md** para registrar escopo, non-goals, validações e regra de parada; o goal passa a carregar um contrato que outra sessão consegue repetir.

**Não confunda:** **AGENTS.md** não é backlog, README nem justificativa criada depois do erro; é instrução operacional que orienta a execução desde o início.
