# Impeccable

Camada de polimento visual/UX depois do gate de conformidade: hierarquia, ritmo, acessibilidade e acabamento profissional.

## Como é usado

Use **Impeccable** como o passe de polimento que roda **depois** do gate de conformidade do design system: com tokens, componentes e contrato já validados, a camada Impeccable sobe hierarquia visual, ritmo, acessibilidade e acabamento profissional.

**Exemplo prático:** na aula [[41-design-system-e-decisao]], uma tela que já passou no gate de conformidade — tokens certos, componentes certos — ainda parece "gerada": o passe Impeccable ajusta hierarquia, espaçamento e ritmo. É polish com critério, não CSS solto por cima do contrato.

**Não confunda:** Impeccable não substitui o gate de conformidade: polir uma tela que viola o design system é maquiar erro. A ordem é fixa — contrato, conformidade, e só então o polish.
