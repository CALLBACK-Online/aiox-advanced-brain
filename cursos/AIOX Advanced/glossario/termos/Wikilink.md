# Wikilink

Link interno entre notas Markdown no estilo Obsidian, escrito com colchetes duplos em torno do nome da nota. O grafo do curso depende de wikilinks que resolvam dentro de `cursos/`.

## Como é usado

Use **Wikilink** para ligar uma aula, termo ou conceito relacionado sem duplicar conteúdo. Escreva o alvo no nome canônico da nota, abra o link para confirmar que resolve e confira a aresta no grafo quando a conexão for importante.

**Exemplo prático:** na aula [[18-yaml-markdown-json-sweet-spot]], use `[[Obsidian]]` e `[[Wikilink]]` para conectar a explicação ao glossário; abra os dois links no vault e corrija qualquer alvo não resolvido antes de publicar a nota.

**Não confunda:** **Wikilink** não é URL nem cria automaticamente a nota de destino. Um link pode estar bem escrito e ainda apontar para uma nota inexistente; a resolução precisa ser verificada.
