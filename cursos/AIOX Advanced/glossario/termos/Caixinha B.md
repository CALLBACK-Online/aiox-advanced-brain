# Caixinha B

Repertório real mas fora do contexto atual. Você guarda, não despeja.

## Como é usado

Use **Caixinha B** para triar repertório durante uma missão: especialidade real que não serve ao contexto atual vai para a caixinha, marcada para depois, em vez de inflar o prompt de agora.

**Exemplo prático:** na aula [[12-repertorio-vs-tecnica]], ao montar o contexto de uma tarefa, você separa o que entra no prompt (repertório que a tarefa exige) do que fica na Caixinha B — aquele conhecimento de outro domínio que é valioso, mas que hoje só polui o contexto.

**Não confunda:** Caixinha B não é lixeira: é retenção deliberada. Descartar seria perder repertório; despejar tudo no prompt atual seria afogar o contexto. Você guarda, não despeja.
