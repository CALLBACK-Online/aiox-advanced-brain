# Spike

Time-box de investigação técnica para reduzir incerteza antes de comprometer Story ou PRD. Gera evidência e decisão, não uma feature eterna.

## Como é usado

Use **Spike** quando uma incerteza técnica impedir a decisão: defina uma pergunta, faça um time-box curto e registre a evidência que orienta a Story.

**Exemplo prático:** na aula [[46-etapas-de-desenvolvimento]], um spike de meio dia responde “a API do fornecedor suporta webhook?”; a resposta entra no PRD e o código exploratório é descartado.

**Não confunda:** Spike não é feature disfarçada: se o time-box acabou e o código foi promovido a produção sem passar pelo ciclo normal, não foi spike — foi atalho sem gate.
