# /code-anatomist

A skill do AIOX para engenharia reversa: investiga o código, extrai arquitetura, domínio, dados, API, dependências e infraestrutura e formaliza a regra de negócio em nove fases.

## Como é usado

Use **/code-anatomist** para entender um brownfield, legado ou código de terceiros antes de mexer: extraia camadas, formalize regras de negócio e produza o mapa que sustenta uma mudança cara.

**Exemplo prático:** na aula [[38-code-anatomy-domain-decoder]], aponte **/code-anatomist** para um repositório herdado; as nove fases entregam o mapa do domínio que orienta o plano de refatoração.

**Não confunda:** **/code-anatomist** não é linter nem revisão de qualidade: ele decodifica o que o sistema faz (domínio e regras de negócio), não julga se o código está bem escrito.

**Frequência nos cursos:** **89** menções (AIOX Advanced: 74 · AIOX Advanced Squads: 15).
