# Portable

Label de maturidade: executável com runtime mínimo (Node/Python + o acervo), sem monorepo AIOX completo.

## Como é usado

Use **Portable** para marcar no catálogo o que executa com runtime mínimo: basta Node/Python e o acervo — sem o monorepo AIOX completo — para a skill ou o squad rodar em outro projeto.

**Exemplo prático:** nas aulas [[67-harness-ambiente-execucao]] e [[68-squad-fora-do-claude-code]], copie o artefato para um projeto destino e rode-o fora do Claude Code com o runtime mínimo declarado.

**Não confunda:** **Portable** não significa zero dependência. O label mede maturidade de execução; compare-o com Study, que orienta estudo e não promete execução.

**Frequência nos cursos:** **8** menções (AIOX Advanced: 8 · AIOX Advanced Squads: 0).
