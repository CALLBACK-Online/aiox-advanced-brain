# MVP

Minimum Viable Product: menor fatia de produto que testa uma hipótese de valor de ponta a ponta com evidência. Exige anti-escopo; não é uma versão inacabada de tudo.

## Como é usado

Use **MVP** para recortar a menor fatia do produto que prova valor com evidência: declare o que entra, o que fica explicitamente fora (anti-escopo) e qual métrica confirma que a fatia funcionou.

**Exemplo prático:** na aula [[46-etapas-de-desenvolvimento]], o MVP de cobrança é emitir e enviar uma fatura real; dashboard, relatórios e automações ficam fora até essa fatia provar valor.

**Não confunda:** MVP não é a versão feia de tudo: é a fatia mínima de uma coisa só, com acabamento suficiente para gerar evidência real de valor.
