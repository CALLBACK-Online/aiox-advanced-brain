# Pipeline canônico

Sequência padrão para um projeto novo: Auto-Clarify → Tech Research em paralelo → Spy/Bench → Code Anatomy quando há código existente → PRD com épicos e Stories prontas. A ordem evita codar antes de conhecer o terreno.

## Como é usado

Use o **Pipeline canônico** quando o terreno for novo ou desconhecido. Clarifique o briefing, pesquise temas em paralelo, compare referências, leia o código existente quando necessário e só então feche a planta no PRD e nas Stories.

**Exemplo prático:** na aula [[40-pipeline-canonico-prd]], para um produto novo em domínio desconhecido, liste três temas de Tech Research, dispare-os em paralelo, faça Spy/Bench com scoring e feche o PRD em épicos e Stories antes de mandar o agente codar.

**Não confunda:** **Pipeline canônico** não é uma cerimônia obrigatória para todo ajuste conhecido nem um relatório que termina sem PRD. Em terreno familiar, enxugue a rota; em terreno novo, não troque pesquisa e comparação por código imediato.
