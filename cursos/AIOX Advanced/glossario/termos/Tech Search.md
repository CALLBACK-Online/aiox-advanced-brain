# Tech Search

Pesquisa técnica rápida e autocontida (decompor → buscar → avaliar → sintetizar) para pergunta delimitada.

## Como é usado

Use **Tech Search** para pergunta técnica delimitada que cabe numa investigação autocontida: decompor a pergunta, buscar, avaliar as fontes e sintetizar uma recomendação rastreável — sem montar o pipeline completo de research.

**Exemplo prático:** "qual biblioteca de retry usar neste stack?" é pergunta fechada: neste acervo, a skill `tech-search` a decompõe, busca, avalia e devolve a recomendação com fontes. Quando a missão pede dossiê multi-fonte ou benchmark, ela sobe para `tech-research` e o squad `research`, como distingue a aula [[36-tech-research-multi-fonte]].

**Não confunda:** Tech Search não é busca rasa — a primeira resposta do buscador colada no chat — nem o Tech Research completo: é o degrau do meio, o menor mecanismo suficiente para pergunta fechada, com as fontes citadas na saída.
