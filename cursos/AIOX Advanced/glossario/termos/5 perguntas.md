# 5 perguntas

Processo, dados únicos, documentação, formato ideal e ciclo de vida. O roteiro para mapear qualquer entidade.

## Como é usado

Responda as **5 perguntas** antes de abrir o terminal, sempre que for modelar ou alterar uma entidade: de qual processo ela participa, quais dados únicos carrega, onde está documentada, qual o formato ideal e qual o ciclo de vida. As respostas viram o contexto que o agente recebe para modelar certo.

**Exemplo prático:** na aula [[13-pensamento-estruturado-antes-do-terminal]], antes de modelar "Aluno" num CRM, o operador responde: participa do processo de matrícula; os dados únicos são e-mail e progresso no curso; a documentação vive no PRD; o formato ideal é tabela relacional; o ciclo de vida vai de lead a aluno formado. Só depois disso escreve o prompt ou a migration.

**Não confunda:** as **5 perguntas** não são formulário burocrático nem checklist de QA — são pensamento estruturado antes do terminal. Pular as perguntas e "deixar o agente decidir" gera modelagem improvisada que se propaga para schema, API e telas.
