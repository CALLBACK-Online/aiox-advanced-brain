# File List

Lista explícita dos arquivos que a Story alterou ou criou. Funciona como evidência de escopo e memória para review, close e ownership.

## Como é usado

Use **File List** para registrar o escopo real enquanto a Story avança: inclua código, testes, stories e documentos alterados, e remova entradas que não foram tocadas antes do handoff.

**Exemplo prático:** uma Story de botão altera `Button.tsx`, seu teste e a story de variantes; ao fechar, o autor atualiza o **File List** com esses três caminhos para o revisor saber onde conferir o aceite.

**Não confunda:** **File List** não é uma lista de tudo que foi lido nem substitui o diff, o aceite ou o Development Log. Ele responde a uma pergunta estreita: quais arquivos pertencem a esta Story?
