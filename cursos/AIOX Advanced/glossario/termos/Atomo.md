# Atomo

A unidade mínima reutilizável da interface, como botão, label, input ou ícone, com tokens e variantes próprios para compor peças maiores.

## Como é usado

Use **Atomo** como base do design atômico: padronize botão, input, label ou ícone com tokens e variantes antes de compor peças maiores.

**Exemplo prático:** na aula [[42-design-atomico-brad-frost]], catalogue o botão uma vez com variantes primária, secundária e desabilitada; um campo de busca já é molécula de input e botão.

**Não confunda:** se dá para decompor em peças menores com sentido próprio, não é átomo: o formulário de busca é molécula; o átomo é o input ou o botão isolado.
