# M2 — Construção de capacidade

## Resultado

Capacidade mínima, preferencialmente reutilizada ou adaptada, capaz de executar uma unidade real do processo.

## Checkpoint

Entregue um **squad mínimo capaz de executar uma unidade real de processo**: decisão REUSE/ADAPT/CREATE, prior art, anti-escopo, papéis, tasks, handoffs, contrato e execução representativa validada.
