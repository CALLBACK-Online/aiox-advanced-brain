# Quiz M1b — Memória e grafo da capacidade

[Módulo M1b](../modulos/M1b-memoria-e-grafo-da-capacidade.md) · [Avaliações](../Assessments.md)

### 1. O PRD pede “um cérebro para a capacidade lembrar a empresa”. Qual é o primeiro movimento?

A. Nomear o job (nervoso, córtex, empregado ou resíduo) e o que o store recusa
B. Instalar o produto com o maior ranking de grafo
C. Colocar o caderno pessoal da equipe no mesmo índice do cliente
D. Abrir um sidecar [Neo4j](https://github.com/neo4j/neo4j) ao lado da wave

### 2. A capacidade precisa das palavras originais da call, auditáveis, sem API no path quente. Qual eixo?

A. Síntese com gap analysis
B. Arquivo fiel (verbatim)
C. Sistema nervoso (goal + board)
D. Banco de grafos no fan-in da wave

### 3. Extract produziu 0 arestas com candidatos > 0 e o run disse “ok”. O que falhou?

A. O ranking de um produto de memória
B. A escolha do modelo
C. O invariante de silêncio (I1) — fail-closed
D. A ausência de um segundo store

### 4. O sintoma é “o agente esquece qual story já mergeou”. Qual é o menor degrau suficiente?

A. Córtex institucional com grafo
B. Caderno pessoal do operador no board
C. Um store único para os quatro jobs
D. Resíduo no disco (ledger / cartão da wave) — não um grafo de conhecimento

<details>
<summary>Gabarito comentado</summary>

1. **A.** Quatro jobs, um store não. Ranking e banco de grafos não escolhem o job.
2. **B.** Palavras originais + offline é arquivo fiel. Síntese é outro eixo.
3. **C.** Zero arestas sem alarme é falha. O run não pode passar.
4. **D.** Fan-in esquecido é job 4. Córtex é o job errado.

</details>

## Transferência

Pegue o PRD da aula 12 e escreva: job, recusa, degrau (0–5) e um Won't. Se o job for 2, acrescente arquivo / síntese / camadas.
