# Quiz M2 — Construção de capacidade

[Módulo M2](../modulos/M2-construcao-de-capacidade.md) · [Avaliações](../Assessments.md)

### 1. O acervo já tem um squad que cobre 80% do caso. Qual decisão segue REUSE > ADAPT > CREATE?

A. Criar outro para manter pureza
B. Adaptar o existente com lacunas explícitas
C. Copiar os agentes sem contratos
D. Substituir por um único prompt

### 2. Qual componente não pode faltar no contrato de um squad?

A. Cor e mascote
B. Dez agentes
C. Entradas, saídas, autoridade, handoffs e gates
D. Um runtime proprietário

### 3. A dor é estreita e um procedimento resolve sozinho. Qual mecanismo usar?

A. Uma skill
B. Um squad
C. Um swarm
D. Um novo curso

### 4. Qual evidência prova que a construção está pronta para avançar?

A. O YAML abre sem erro
B. O agente responde uma saudação
C. O README está longo
D. Um caso representativo atravessa o fluxo e produz artefato validado

<details>
<summary>Gabarito comentado</summary>

1. **B.** A adaptação preserva prior art e torna a lacuna verificável.
2. **C.** Contratos operacionais evitam coordenação implícita.
3. **A.** O menor mecanismo suficiente reduz custo e drift.
4. **D.** Prontidão exige fluxo e evidência, não presença de arquivos.

</details>
