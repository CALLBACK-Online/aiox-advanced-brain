### 1. Uma única capacidade repetível cabe em instruções e scripts próprios. O que criar primeiro?

- A. Uma skill
- B. Um squad Pro
- C. Um novo produto SaaS
- D. Um board

### 2. Qual regra vem antes de criar qualquer asset?

- A. CREATE sempre
- B. REUSE → ADAPT → CREATE
- C. Clonar sem pesquisa
- D. Maximizar agentes

### 3. Quando Squad Creator Pro é justificado?

- A. Sempre que houver um arquivo Markdown
- B. Quando a capacidade exige extração de expertise, elite minds e gates avançados
- C. Para uma task trivial
- D. Para evitar critérios de aceite

### 4. Qual prova mínima um squad novo deve apresentar?

- A. Muitos agentes
- B. Estrutura válida, task real executada, output verificável e gate aprovado
- C. Um nome criativo
- D. Apenas README

<details>
<summary>Gabarito comentado</summary>

**1. A** — Comece pela menor unidade que resolve o problema.  
**2. B** — A heurística evita duplicação e custo desnecessário.  
**3. B** — O Pro se paga quando profundidade e fidelidade são requisitos reais.  
**4. B** — Anatomia sem comportamento validado não prova capacidade.
