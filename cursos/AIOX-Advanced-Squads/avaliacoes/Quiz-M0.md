# Quiz M0 — Escolha, pesquisa e domínio

[↑ M0](../modulos/M0-escolha-pesquisa-dominio.md) · [Avaliações](../Assessments.md)

### 1. Você precisa comparar evidências de mercado antes de escolher uma direção. Qual squad entra primeiro?

- A. Advisory Board
- B. Research
- C. Domain Decoder
- D. Code Anatomist

### 2. Qual fronteira separa Code Anatomist de Domain Decoder?

- A. O primeiro mapeia o sistema inteiro; o segundo aprofunda regras e linguagem do negócio
- B. O primeiro vende; o segundo escreve copy
- C. O primeiro só cria banco; o segundo só cria API
- D. Não existe diferença

### 3. Uma reunião de decisão começa sem dados básicos que poderiam ser pesquisados. O que fazer?

- A. Pedir votação imediata
- B. Escolher o advisor mais famoso
- C. Fazer a pesquisa necessária e depois deliberar
- D. Criar um novo squad

### 4. Qual evidência fecha corretamente uma execução de Domain Decoder?

- A. Uma lista de arquivos sem interpretação
- B. Um catálogo rastreável de regras, termos, decisões e fontes
- C. Um pitch comercial
- D. Um calendário editorial

<details>
<summary>Gabarito comentado</summary>

**1. B** — Research sustenta a decisão com evidência.  
**2. A** — Anatomia sistêmica e regras de domínio são profundidades diferentes.  
**3. C** — Deliberação boa explicita lacunas e busca dados antes do conselho.  
**4. B** — O valor está na rastreabilidade do conhecimento extraído.

</details>
