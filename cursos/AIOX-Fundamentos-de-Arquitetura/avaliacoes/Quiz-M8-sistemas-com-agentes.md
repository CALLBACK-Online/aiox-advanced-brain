# Quiz 8 — Sistemas com agentes

### 1. O que diferencia tool de skill neste curso?

A. Tool executa uma capacidade; skill orienta quando e como compô-la  
B. Skill é sempre um banco de dados  
C. Tool é apenas documentação  
D. Não existe diferença operacional

### 2. Quando um único agente tende a ser melhor que um squad?

A. Quando o trabalho é coeso, cabe no contexto e não exige perspectivas independentes  
B. Quando se deseja o máximo de handoffs  
C. Quando ninguém definiu o objetivo  
D. Quando toda etapa precisa de aprovação humana

### 3. Onde human-in-the-loop é mais importante?

A. Em decisões irreversíveis, ambíguas ou com alto impacto externo  
B. Apenas ao corrigir ortografia  
C. Nunca, porque agentes não falham  
D. Em cada token gerado, sem exceção

### 4. Qual evidência demonstra uma arquitetura agentic completa?

A. Muitos nomes de agentes  
B. Objetivo, contratos, estado, ferramentas, limites, observabilidade, falhas e gates verificáveis  
C. Um prompt longo sem testes  
D. Um diagrama sem responsabilidades

<details>
<summary>Gabarito comentado</summary>

1. **A.** A tool oferece ação; a skill codifica procedimento, critérios e contexto de uso.  
2. **A.** Dividir sem independência aumenta custo de coordenação e fan-in.  
3. **A.** Supervisão humana deve acompanhar risco, ambiguidade e reversibilidade.  
4. **B.** Arquitetura é um conjunto de decisões testáveis, não uma coleção de rótulos.

</details>
