# AGENT-GUIDE — AIOX Design v2

## Algoritmo teach

1. Uma competência por aula — abra só a aula da progressão.
2. Exija prática + evidência; não declare pronto no discurso.
3. Capstone: **Storybook rodando** ou bloqueio de ambiente (não é Done).
4. Ancore em `skills/` e `squads/` reais.
5. Brand estratégico → squad brand; tradução visual → este curso.

## Roteamento

| Intenção | Aulas |
|----------|-------|
| Decisão vs gosto | 01–02 |
| Referências / Pinterest | 03 |
| Tema vs DS / top-down | 04–05 |
| Brand → tokens | 06 + ponte brand |
| AI-look | 07 |
| DESIGN.md / tokens / taxonomia | 08–10 |
| Storybook SoT / install / variantes | 11–14 |
| Governança / multi-produto / ciclo | 15–17 |
| Portão / skill-squad / capstone | 18–20 |

```text
Aula: cursos/AIOX-Design/aulas/NN-…
Competência: {1 frase}
```
