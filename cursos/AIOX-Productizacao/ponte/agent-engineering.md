# Ponte — Agent Engineering → Productização

## Entrada desta trilha

Você não precisa concluir todo Agent Engineering. Precisa trazer:

- capacidade com entrada e saída observáveis;
- uma execução real;
- limites e falhas conhecidos;
- alguma medida de tempo, custo, erro ou risco;
- evidência que outra pessoa consiga inspecionar.

## O que permanece em Agent Engineering

- taxonomia de task, skill, workflow e squad;
- entidade e ciclo de vida;
- runners, harness e orquestração;
- paralelismo, routing e waves;
- banco, deploy, CI/CD e prontidão de produção.

Path da trilha: `cursos/AIOX-Agent-Engineering/`.

## Handoff mínimo

```yaml
capacidade:
  entrada: ""
  saída: ""
  usuário_atual: ""
  evidência: ""
  tempo_e_custo: ""
  falhas_conhecidas: []
  limites: []
```

Se o handoff não pode ser preenchido, volte à engenharia. Se pode, comece pelo [wedge](../aulas/01-service-as-software.md).
