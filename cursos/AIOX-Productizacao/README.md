## Entrada

Uma capacidade real com saída observável e pelo menos uma evidência de valor. Se a capacidade ainda não é executável, conclua primeiro o AIOX Agent Engineering (`cursos/AIOX-Agent-Engineering/`).

## Resultado

Um Productization Decision Pack: wedge, oferta de uma página, ROI auditável, experimento de distribuição, escolha de formato e gate do próximo estágio.

## Anti-escopo

- Engenharia, harness e deploy da capacidade pertencem ao AIOX Agent Engineering.
- Contrato visual pertence ao AIOX Design.
- Este curso não substitui validação com usuários ou clientes.
- Não é curso completo de vendas, pricing, copywriting ou growth.
- Não ensina billing, Stripe, multi-tenancy nem arquitetura SaaS.
- Não promete receita e não aceita ROI sem baseline ou premissas.

## Como estudar

Use uma única capacidade real durante as seis aulas. Cada prática alimenta o mesmo Decision Pack:

```text
capacidade → wedge → oferta → distribuição → formato → estágio → decisão
```

1. Faça a prática sem ajuda do agente.
2. Use o prompt da aula para receber crítica.
3. Marque cada afirmação como fato, hipótese ou desconhecido.
4. Só avance se atingir o portão da aula.
5. Feche no capstone com um experimento de até 14 dias.

## Ordem no acervo

```text
Obsidian + IA → Arquitetura → Fundamentals → Advanced
                                              ↓ capacidade comprovada
                         Agent Engineering ──→ Productização
                                              ↓ missão especializada
                                  squads de copy, sales ou Hormozi
```

Quem já chega do Advanced com capacidade executável e evidência de valor pode entrar direto. Quem ainda precisa construí-la passa antes por Agent Engineering. Paths das trilhas irmãs aparecem como texto para preservar o curso autocontido: `cursos/AIOX-Agent-Engineering/`, `cursos/AIOX Advanced/` e `cursos/AIOX-Advanced-Squads/`.
