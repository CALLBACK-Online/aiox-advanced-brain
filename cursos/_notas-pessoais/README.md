# Notas pessoais de estudo

Esta pasta é o **espaço local** para captura de aprendizado sobre o AIOX Advanced **sem alterar** as aulas canônicas.

## Layout sugerido

```text
_notas-pessoais/
  inbox/     # captura rápida
  notes/     # notas destiladas
  MOCs/      # mapas de conteúdo pessoais
  cards/     # resumos / revisão
```

Crie as subpastas quando precisar. O conteúdo pessoal permanece no seu clone (ver `.gitignore` na raiz do repositório); só este `README.md` é versionado.

## Como o agent ajuda

| Objetivo | Skill |
|----------|--------|
| Visão geral do segundo cérebro | `skills/aiox-brain/` |
| Navegar o curso no Obsidian | `skills/obsidian-course-vault/` |

## Regras

1. Não edite `lessons/`, `aulas/`, `modulos/` canônicos para “ficar do seu jeito”.
2. Sempre linke de volta à fonte (`[[aula]]` ou path relativo).
3. Se for executar no projeto real, copie `skills/` / `squads/` para o destino — não execute “dentro” da nota.

## Vault Obsidian

- Estudo do método: abra `Cursos/AIOX Advanced/` como vault.
- Notas pessoais: ou inclua `Cursos/` como vault (vê canônico + `_notas-pessoais/`), ou mova/copie notas para o seu vault pessoal depois de destilar.
