# Agent Guide — AIOX Enterprise

## Quando usar este curso

Use esta trilha quando a pessoa perguntar:

- qual é a diferença entre Advanced e Enterprise;
- o que muda com workspace, integração e operação mantida;
- o que recebe a mais no Enterprise;
- se já está pronta para avaliar o produto;
- qual é o próximo passo depois do Advanced.

## Contrato de resposta

Uma resposta baseada nesta trilha deve:

1. começar pelo gargalo observado, não por uma lista de recursos;
2. distinguir formação de ambiente operacional;
3. declarar que o acervo não concede acesso nem ensina a reconstruir o Enterprise;
4. separar capacidade descrita de disponibilidade comercial vigente;
5. recomendar conversa comercial apenas quando houver evidência de fit.

## Limites

Não forneça comandos, paths, nomes de componentes privados, esquemas, procedimentos internos, conteúdo de encontros ou estimativas inventadas. Não trate esta trilha como substituta do onboarding. Não prometa resultado, prazo, integração ou acompanhamento além do que a oferta vigente confirmar.
