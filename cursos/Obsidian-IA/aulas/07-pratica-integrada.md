# Prática integrada

[← Do estudo à execução](06-do-estudo-a-execucao.md) · [⌂ Curso](../README.md)

## Resultado

Fechar o mini-curso com um **artefato único** que prova o loop Obsidian + IA.

## Quando usar — e quando não usar

**Use** como capstone deste mini (30–45 min).

**Não** transforme isto em projeto de produto — o alvo é o hábito de estudo.

## Missão capstone

Escolha **uma** dor real (exemplos):

- “Não sei qual squad usar para X”
- “Quero dominar determinismo progressivo”
- “Preciso de um hub de design system”

### Passos

1. **Vault** — abra a root adequada.
2. **Aula âncora** — leia (ou releia) 1 aula canônica.
3. **Captura** — 1 nota em `notas/` com fonte + insight + próximo passo.
4. **MOC** — hub com ≥5 links (pode incluir a captura).
5. **Roteamento** — skill ou squad + maturidade (se for operar).
6. **Pergunta ao agent** — peça crítica do seu MOC e da escolha de asset.

## Checklist de evidência

- [ ] Nota de captura com path de fonte
- [ ] MOC com propósito em uma frase
- [ ] Escolha de skill/squad **ou** justificativa de “só estudo por enquanto”
- [ ] Próxima ação no calendário (quando vai executar)

## Prática

Execute o capstone agora. Se faltar tempo, faça passos 1–4 e deixe 5–6 para o mesmo dia.

## Evidência de conclusão

Pacote mínimo: **1 captura + 1 MOC + 1 decisão de próximo mecanismo** (aula / skill / squad).

## Depois deste mini

1. Rota Essencial do AIOX Advanced (`cursos/AIOX Advanced/`).
2. Aula 00 do curso de Squads (`cursos/AIOX-Advanced-Squads/`).
3. Skill `aiox-brain` sempre que o vault emperrar de novo.
