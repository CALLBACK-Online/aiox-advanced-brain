- [ ] `COURSE-BRIEF.md` com `status: approved`, `approved_by`, `approval_date`, `approved_artifact`, `approval_scope`
- [ ] `course-outline.md` com gate humano equivalente
- [ ] `course-spec.json` referencia ambos em `approval_artifacts`
- [ ] `check_approvals.py` PASS antes do scaffold
- [ ] `scaffold_course.py --spec docs/producao-cursos/<id>/course-spec.json` (bloqueia destino existente e approval ausente)
- [ ] Núcleo: README, aulas, fonte/proveniência e harness
- [ ] Artefatos condicionais justificados (módulos, AGENT-GUIDE, mapas, glossário, templates, pontes)
- [ ] Avaliação alinhada ao perfil (quiz/capstone/rubrica ou diagnóstico)
- [ ] Gabarito balanceado A/B/C/D quando houver múltipla escolha
- [ ] Pontes se houver vizinho

- [ ] `catalog.json` + hub `cursos/README.md`
- [ ] AGENTS/CLAUDE se rota nova de roteamento
