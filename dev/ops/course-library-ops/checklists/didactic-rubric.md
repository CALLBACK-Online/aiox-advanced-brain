# Rubrica didática operacional — fallback

Fonte preferencial: `skills/teach/SKILL.md` do acervo de destino. Usar este
fallback somente quando ela não existir. Não confundir com a skill global de
tutoria HTML chamada `teach`.

Cada dimensão fecha em `PASS` ou `FAIL`; não calcular score 0–100 sem calibração.

1. **Objetivo verificável** — verbo observável, contexto e critério de sucesso.
2. **Ancoragem no acervo** — exemplos e claims apontam para assets/fontes reais.
3. **Exercício ou checkpoint** — prática curta produz resposta, decisão ou artefato.
4. **Navegação** — módulo, anterior/próxima e README resolvem no próprio curso.
5. **Ponte método ↔ operação** — quando aplicável, a transição curricular existe e é bidirecional.
6. **Terminologia consistente** — vocabulário não deriva do glossário/curso.

Ledger obrigatório:

```text
módulo → aula → dimensão/gate → evidência → ação corretiva → status
```

Sinal automático ajuda a localizar risco, mas não aprova semântica. Resolver todo
`PENDING`, corrigir todo `FAIL` e executar o validador do curso entre lotes.
