# CLAUDE.md

Siga **`AGENTS.md`** como contrato.

## Gate

1. Classifique: estudo vs produção de curso vs validação.
2. Estudo → `cursos/` + AGENT-GUIDE do curso.
3. Produção de acervo/curso → `dev/ops/course-library-ops/SKILL.md` (ou skill instalada em `.claude/skills/course-library-ops/`).
4. Sempre feche mudanças estruturais com `npm run validate`.

Não invente runtime AIOX completo neste pacote a menos que o acervo o inclua.
